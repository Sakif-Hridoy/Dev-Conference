# DevConf 2026

A modern and responsive-inspired landing page for a fictional developer conference, designed and developed using **HTML5** and **CSS3**. This project showcases a clean user interface, organized layouts, and modern CSS techniques while maintaining simplicity without using JavaScript or external CSS frameworks.

## Project Overview

**DevConf 2026** is a conference website created for developers, software engineers, founders, and technology enthusiasts. The website presents essential conference information in a professional and visually appealing layout.

The project focuses on writing clean semantic HTML and organized CSS while following modern frontend development practices.

---

## Features

* Modern and clean landing page
* Responsive-friendly layout structure using Flexbox and CSS Grid
* Professional Hero section
* Meet the Speakers section
* Conference Tracks section
* Pricing / Secure Your Spot section
* Professional Footer
* Consistent typography and spacing
* Card-based UI design
* Rounded corners with subtle shadows
* Reusable button styles
* Organized project structure

---

## Sections

### Hero

A visually engaging hero banner introducing DevConf 2026 with a clear call-to-action.

### Meet the Speakers

Highlights keynote speakers using a modern card-based gallery layout.

### Conference Tracks

Showcases multiple technical learning tracks, including:

* AI & Machine Learning
* Cloud & DevOps
* Frontend Engineering
* Backend Engineering
* Cyber Security
* Mobile Development
* Data Engineering
* Open Source
* UI/UX & Product Design
* Career Growth & Leadership

### Secure Your Spot

Displays conference pricing packages for different attendee types.

### Footer

Provides copyright information and useful navigation links.
