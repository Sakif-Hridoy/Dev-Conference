# My Prompts to Build the AI-Generated Section

The **Conference Tracks** section of this project was created with the assistance of AI. Below are the prompts I used throughout the process.

## Prompt 1: Finding a Relevant Section

I first asked the AI to suggest a section that would naturally fit a developer conference website instead of generating code immediately.

**Prompt:**

> "Now, already my previous query history to help me building my site, you already know that this is a dev conference website. Programming Hero gave me a challenge that I have to make a section that is relevant to my website type and this should be completely done by you, Mr AI."

---

## Prompt 2: Brainstorming Ideas

Before requesting any code, I wanted to explore ideas that would be meaningful for a developer conference and appreciated by developers, organizers, and business professionals.

**Prompt:**

> "At first, give me no code. Give me some related and highly recognized concepts, ideas, and contents which could be appreciated by any senior programmer or related business person for why I am making this site for them."

After reviewing the suggested ideas, I selected **Conference Tracks** as the most suitable section for my website.

---

## Prompt 3: Generating the First Version

I then asked the AI to generate the section using only HTML and CSS while keeping the design consistent with the rest of my project.

**Prompt:**

> "I am interested about conference tracks. So now, prepare me a section with just HTML and CSS. From my previous code, you already know that I am not working with responsiveness, only pure HTML and CSS, but using modern concepts like Flexbox and Grid. Don't use animations or advanced CSS. Keep the similarity of width, heights, aspect ratios, and overall design with my existing sections."

---

## Prompt 4: Improving the Generated Section

The first generated version did not fully match my expectations, so I requested a revised version with more comprehensive content and a better layout.

**Prompt:**

> "No, I wasn't satisfied. Include all of the conference tracks you mentioned, add a proper headline, a short description, and related icons. Display the contents using a gallery or card-based layout so that all tracks are presented clearly."

---

## Final Outcome

Using these prompts, the AI generated the **Conference Tracks** section, which was then integrated into the DevConf 2026 website while maintaining the same visual style and layout as the rest of the project.
